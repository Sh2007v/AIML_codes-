CSS SYNTAX:
    selector {
        property: value;
    }
    e.g.:
        p {
            color: red;
            text-align: center;
        }

CSS Selectors
    .used to select HTML tags for styling

    Types:
        Simple Selectors – Select elements by name, id, or class.
        Combinator Selectors – Select elements based on relationships.
        Pseudo-class Selectors – Select elements in a specific state (e.g., :hover).
        Pseudo-element Selectors – Style specific parts of an element (e.g., ::first-letter).
        Attribute Selectors – Select elements based on attributes.

    Grouping Selectors
        1.Universal Selector (*):
            to apply style on every element
            *{
                text-align: center;
                color: blue;
            }
        2.Grouping Selector(,):
            to apply style on particular gtoup of elements
            h1, h2, p{
                text-align: center;
                color: red;
            }
        | Selector           | Purpose                                                |
        | ------------------ | ------------------------------------------------------ |
        | `#id`              | Selects an element with a specific **id**              |
        | `.class`           | Selects all elements with a specific **class**         |
        | `*`                | Selects **all** HTML elements                          |
        | `element`          | Selects all elements of a specific tag (e.g., `p`)     |
        | `element, element` | Selects multiple elements together (e.g., `h1, h2, p`) |
