CSS SYNTAX:
    selector {
        property: value;
    }
    e.g.:
        p {
            color: red;
            text-align: center;
        }

CSS Selectors
    .used to select HTML tags for styling

    Types:
        Simple Selectors – Select elements by name, id, or class.
        Combinator Selectors – Select elements based on relationships.
        Pseudo-class Selectors – Select elements in a specific state (e.g., :hover).
        Pseudo-element Selectors – Style specific parts of an element (e.g., ::first-letter).
        Attribute Selectors – Select elements based on attributes.

    Grouping Selectors
        1.Universal Selector (*):
            to apply style on every element
            *{
                text-align: center;
                color: blue;
            }
        2.Grouping Selector(,):
            to apply style on particular gtoup of elements
            h1, h2, p{
                text-align: center;
                color: red;
            }
        | Selector           | Purpose                                                |
        | ------------------ | ------------------------------------------------------ |
        | `#id`              | Selects an element with a specific **id**              |
        | `.class`           | Selects all elements with a specific **class**         |
        | `*`                | Selects **all** HTML elements                          |
        | `element`          | Selects all elements of a specific tag (e.g., `p`)     |
        | `element, element` | Selects multiple elements together (e.g., `h1, h2, p`) |

        CSS Borders
            1. border-style : 
                p.dotted{
                    border-style: dotted;
                }

                p.dashed{
                    border-style: dashed;
                }

                p.solid{
                    border-style: solid;
                }

                p.double{
                    border-style: double;
                }

            2.Multiple Border Styles:
                p{
                    border-style: dotted dashed solid double;
                }

            | Property       | Purpose                      |
            | -------------- | ---------------------------- |
            | `border-style` | Specifies the type of border |
            | `dotted`       | Dotted border                |
            | `dashed`       | Dashed border                |
            | `solid`        | Solid border                 |
            | `double`       | Double border                |
            | `groove`       | 3D grooved border            |
            | `ridge`        | 3D ridged border             |
            | `inset`        | 3D inset border              |
            | `outset`       | 3D outset border             |
            | `none`         | Removes the border           |
            | `hidden`       | Hides the border             |

        CSS Margins
            p{
                margin-top: 100px;
                margin-right: 150px;
                margin-bottom: 100px;
                margin-left: 80px;
            }
        Margin values:
            auto : browser calculates the margin
            length : fixed value
            % : percentage of the parent element's width
            inherit : inherits the margin values from parent.
