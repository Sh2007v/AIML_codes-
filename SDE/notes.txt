Correlation Analysis
    stats method to measure the relation btw two vars
    tells wether one var changes when another var changes
    relationship is measured using the correlation coefficient(r)

    Correlation Coefficient(r)
        -1<r<1
        indicates:
            direction of relationship
            strength of relationship
        
        Direction of Correlation

        | Value of r | Direction      | Meaning                                           |
        | ---------- | -------------- | ------------------------------------------------- |
        | **r > 0**  | Positive       | Both variables increase or decrease together.     |
        | **r < 0**  | Negative       | One variable increases while the other decreases. |
        | **r = 0**  | No Correlation | No linear relationship between the variables.     |

        Strength of Correlation

        | |r| Value     | Strength              |
        | ------------- | --------------------- |
        | **0.0 – 0.1** | No correlation        |
        | **0.1 – 0.3** | Low correlation       |
        | **0.3 – 0.5** | Medium correlation    |
        | **0.5 – 0.7** | High correlation      |
        | **0.7 – 1.0** | Very high correlation |
    
    Positive and Negative Correlation
        Positive Correlation
            both vars move in same direction
            one increases, other also increases
            r>0
            e.g.:
                height and shoe size
                r=+0.95: very high positive correlation
            
        Negative Correlation
            both vars move in opposite direction
            one var increases, other decreases
            r<0
            e.g:
                screen time and exam score
                r=-0.54: high negative correlation
            
        Weak/No correlation
            no or little correlation between the vars

    Data Storytelling
        explaining the meaning of a graph or data in simple words
        Steps for reading a correlation graph
            state the vars
            describe direction
            mention r
            give a conclusion

            e.g.:

                Screen Time vs Exam Score
                The graph shows a downward trend.
                r = −0.54, indicating a high negative correlation.
                Conclusion: Students who spend more time on screens tend to 
                            have lower exam scores.
    
    Correlation btw more than two variables
        Correlation Matrix
            table showing correlation coefficients between every pair of vars in a 
            dataset
            helps analyze multiple variables at same time
        Correlation Heatmap
            graphical representation of a correlation matrix using colors
            red:strong positive correlation
            blue:strong negative correlation
            light/pale: little or no correlation
            diagonal values are 1.00 
        Types of Correlation Methods
            1.Pearson Correlation (r):
                measures the strength and direction of a linear relationship btw two numerical vars
            2.Spearman Correlation (rho):
                measures the relationship based on rank of data

                
Regression Analysis
    to predict the value of one var based on one or more variable
    maths eqn used to predict this is called regression model

    Measuring influence
        determines how much one var affect another
    Prediction
        estimates the value of a var using other vars

    Correlation vs Regression
        Correlation
            strength and direction of relationship btw vars
        Regression
            provides an eqn to predict the values

    Linear Regression
        used to predict a dependent var using one or more indepen. var
        Types of Linear Regression:
            Simple Linear Regression
                one independent var is used to predict the dependent var
                eqn: y = mx+c

            Multiple Linear Regression
                used to predict the dependent var using one or more independent vars.
            
            R^2(Coefficient of Determination)
                measures how well regression model explains the variation
                Higher R^2 : Better prediction.

    Skewness
        describes how asymmetric the given data is.

        Types:
            | Type                 | Shape             | Mean vs Median | Skew Value |
            | -------------------- | ----------------- | -------------- | ---------- |
            | **Right / Positive** | Long tail → right | Mean > Median  | > 0        |
            | **Left / Negative**  | Long tail ← left  | Mean < Median  | < 0        |
            | **Symmetric**        | Balanced          | Mean ≈ Median  | ≈ 0        |
        
        Handling strong skewness
            log transformation : log_income = np.log1p(income)
            makes the distribution more balanced

        Important functions:
            income.skew()       # Check skewness
            np.log1p(income)     # Log transformation
            np.expm1(value)      # Reverse log transformation

        Outlier
            value that lies far away from most of values
                :genuine extreme value
                :data-entry error
            detected by z-value, IQR and boxplots
            
            Types:
                1.Point outlier :
                    a single value far from the rest of values
                2.Contextual outlier:
                    value normal in general cases but exceptional in some contexts
                3.Collective outlier:
                    group of values forming difference
        
            IQR vs Z-Score
                IQR - skewed data
                Z-score - symmetric data
            
            Handling outliers
                Remove:
                    remove observation when :
                        it is data entry error
                Cap:
                    replace the value when:
                        it is real but unusallly very high / low

            Sampling and Hypothesis testing
                Sampling: process of extracting information by selecting smaller group from larger group.

                Sampling methods.
                    1. Simple random sampling : equal chance of selection of items
                    2. Systematic sampling : selecting every kth element
                    3. Stratified Sampling : divide the popln into strata and then study them.
                    4. Cluster Sampling : divide the population into cluster and study them seperately.
                    5. Convenience Sampling : select people easiest to reach

                        Stratified sampling ensures that every group is represented
                    
                1.Sampling Distribution
                    Sample variability : distribution of different sample means calculated from a given population
                
                2.CLT(Central Limit Theorem)
                    for large sample space, the distribution becomes bell shaped
                    centered around the population mean
                    it is true even the original population is skewed

                3.Standard Error : spread of sampling distribution 
                                SE= (sigma)/(n)^1/2;
                
                Hypothesis Testing
                    uses sample data to evaluate a claim about the population

                    Main Hypothesis
                        1.Null Hypothesis
                            represents no effect or no difference
                        2.Alternative Hypothesis
                            represents claim or effect we suspect
