Lists:

ordered + duplicate values + mutable

numbers = [10, 20, 30, 40, 50]
print(numbers)

Access and modify

numbers = [10, 20, 30, 40, 50]

print(numbers[0])   # 10
print(numbers[2])   # 30
print(numbers[-1])  # 50 (last element)

numbers[1] = 25
print(numbers)      # [10, 25, 30, 40, 50]

4. Common list methods

Method	Purpose	Example
append(x)	Adds one item at the end	a.append(60)
insert(i, x)	Adds an item at an index	a.insert(1, 15)
remove(x)	Removes the first matching value	a.remove(20)
pop(i)	Removes and returns an item	a.pop(0)
sort()	Sorts the list in place	a.sort()
reverse()	Reverses the list in place	a.reverse()
len(a)	Returns the number of items	len(a)

Slicing
a = [10, 20, 30, 40, 50]

print(a[1:4])  # [20, 30, 40]
print(a[:3])   # [10, 20, 30]
print(a[2:])   # [30, 40, 50]
print(a[::-1]) # [50, 40, 30, 20, 10]

traversing lists
numbers = [10, 20, 30]

for num in numbers:
    print(num)



important methods for lists

1	append(x)	        Adds one element at the end	        a.append(40)
2	extend(iterable)	Adds multiple elements	            a.extend([40, 50])
3	insert(i, x)	    Inserts an element at an index	    a.insert(1, 15)
4	remove(x)	        Removes the first matching value    a.remove(20)
5	pop(i)	            Removes and returns an element	    a.pop(1)
6	clear()	            Removes all elements	            a.clear()
7	index(x)	        Returns the first matching index	a.index(30) → 2
8	count(x)	        Counts occurrences of a value	    a.count(20) → 2
9	sort()	            Sorts the list in place	            a.sort()
10	reverse()	        Reverses the list in place	        a.reverse()
11	copy()	            Creates a shallow copy	            b = a.copy()
12	len(a)	            Number of elements	                len(a) → 4
13	max(a)	            Largest element	                    max(a) → 30
14	min(a)	            Smallest element	                min(a) → 10
15	sum(a)	            Sum of numeric elements	            sum(a) → 80
16	sorted(a)	        Returns a new sorted list	        sorted(a)
17	a[i]	            Access an element by index	        a[0] → 10
18	a[start:end]	    Extract a slice	                    a[1:3] → [20, 30]
19	x in a	            Checks membership	                20 in a → True
20	a + b	            Concatenates two lists	            [1, 2] + [3] → [1, 2, 3]

21	enumerate(a)	    Gives each element with its index	    list(enumerate(['a', 'b'])) → [(0, 'a'), (1, 'b')]
22	reversed(a)	        Returns a reverse iterator	            list(reversed([1, 2, 3])) → [3, 2, 1]
23	any(a)	            True if at least one element is truthy	any([0, 0, 5]) → True
24	all(a)	            True if every element is truthy	        all([1, 2, 3]) → True
25	map()	            Applies a function to each element	    list(map(lambda x: x*2, [1, 2])) → [2, 4]
26	filter()	        Keeps elements that pass a condition	list(filter(lambda x: x > 2, [1, 3, 4])) → [3, 4]
27	zip()	            Combines corresponding elements	        list(zip([1, 2], ['a', 'b'])) → [(1, 'a'), (2, 'b')]
28	id()	            Returns an object's identity 
                        (useful for understanding references)	id(a)
29	del	                Deletes an element or slice	            del a[0]
30	List comprehension	Creates a list using an expression      [x*x for x in [1, 2, 3]] → [1, 4, 9]
