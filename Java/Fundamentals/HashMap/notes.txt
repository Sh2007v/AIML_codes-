HashMap
    : key value pair 
    : Syntax : HashMap <Integer, String> students = new HashMap<>();
    : Important properties :
        1. keys are unique
        2. values can duplicate
        3. keys are to retrieve values
        4. does not guarantee order
        5. allows one null key


    : Important methods
| Method            | Syntax                      | Use / Meaning                                        | Example                                 |
| ----------------- | --------------------------- | ---------------------------------------------------- | --------------------------------------- |
| `put()`           | `map.put(key, value);`      | Adds a new key-value pair or updates an existing key | `map.put(101, "Aman");`                 |
| `get()`           | `map.get(key);`             | Gets the value associated with a key                 | `map.get(101);` → `"Aman"`              |
| `remove()`        | `map.remove(key);`          | Removes the key-value pair                           | `map.remove(101);`                      |
| `containsKey()`   | `map.containsKey(key);`     | Checks whether a key exists                          | `map.containsKey(101);` → `true`        |
| `containsValue()` | `map.containsValue(value);` | Checks whether a value exists                        | `map.containsValue("Aman");` → `true`   |
| `size()`          | `map.size();`               | Returns number of key-value pairs                    | `map.size();` → `3`                     |
| `isEmpty()`       | `map.isEmpty();`            | Checks whether the HashMap is empty                  | `map.isEmpty();` → `false`              |
| `clear()`         | `map.clear();`              | Removes all key-value pairs                          | `map.clear();`                          |
| `keySet()`        | `map.keySet();`             | Returns all keys                                     | `map.keySet();` → `[101, 102, 103]`     |
| `values()`        | `map.values();`             | Returns all values                                   | `map.values();` → `[Aman, Rahul, Ravi]` |
