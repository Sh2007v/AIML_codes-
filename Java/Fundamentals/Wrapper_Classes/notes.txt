WRAPPER CLASSES
    classes that convert primitive data types into objects

    | Primitive | Wrapper     |
    | --------- | ----------- |
    | `int`     | `Integer`   |
    | `double`  | `Double`    |
    | `char`    | `Character` |
    | `boolean` | `Boolean`   |
    | `float`   | `Float`     |
    | `long`    | `Long`      |
    | `short`   | `Short`     |
    | `byte`    | `Byte`      |

    Autoboxing:
        conversion from primitive to wrapper object
        e.g:
            int x = 10;
            Integer obj = x;   // Autoboxing
    
    Unboxing:
        opposite of autoboxing
        e.g:
            Integer obj = 20;
            int x = obj;       // Unboxing
