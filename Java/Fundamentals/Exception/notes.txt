Java Exceptions
    organised in hierarchy

                 Object
                    ↓
               Throwable
               /         \
              /           \
          Error         Exception
                          /      \
                         /        \
          RuntimeException       Other Exceptions
                |
        ┌───────┼────────┐
        ↓       ↓        ↓
   NullPointer  Arithmetic  ArrayIndexOutOfBounds
   Exception    Exception       Exception


1.Throwable
    root class of everything which can be thrown by java exception mechanism
    subclasses:
        error
        Exception

        1.Error: serious problems that apps should not try to handle
        2.Exception: conditions that can be handled by programs in some cases.
                Types:
                    Checked exceptions : checked by the compiler
                                       : handle them by using try-catch or declare them using throws

                                       Syntax : 
                                       try {
                                            // risky code
                                        } catch (IOException e) {
                                            System.out.println("File error");
                                        }
                    
                    Unchecked exceptions : subclasses of runtime error
                                         : caused by programming mistakes
                                         
                
                Simple heirerchy 
                Throwable
                    │
                    ├── Error
                    │       ├── OutOfMemoryError
                    │       └── StackOverflowError
                    │
                    └── Exception
                    │
                    ├── RuntimeException
                    │   ├── ArithmeticException
                    │   ├── NullPointerException
                    │   ├── NumberFormatException
                    │   └── ArrayIndexOutOfBoundsException
                    │
                    └── Checked Exceptions
                    ├── IOException
                    ├── SQLException
                    └── FileNotFoundException

        try block:
                 contains risky code

                 Syntax:
                    try{
                        //Risky_Code;
                    }
                    catch{
                        //solution if error occurs;
                    }
        
        catch block:
                to handle the error

//IMPORTANT EXCEPTIONS 

unchecked_exception

| Exception                         | When it occurs                      | Example                             |
| --------------------------------- | ----------------------------------- | ----------------------------------- |
| `ArithmeticException`             | Invalid arithmetic operation        | `10 / 0`                            |
| `NullPointerException`            | Using an object that is `null`      | `str.length()` when `str == null`   |
| `NumberFormatException`           | Invalid String → number conversion  | `Integer.parseInt("abc")`           |
| `ArrayIndexOutOfBoundsException`  | Invalid array index                 | `arr[10]` when size is 5            |
| `StringIndexOutOfBoundsException` | Invalid String index                | `"Hello".charAt(10)`                |
| `InputMismatchException`          | Wrong input type with `Scanner`     | `nextInt()` but user enters `"abc"` |
| `IllegalArgumentException`        | Invalid argument passed to a method | Invalid method parameter            |
| `ClassCastException`              | Invalid object type casting         | Wrong object cast                   |

checked_exception

| Exception                | When it occurs                 |
| ------------------------ | ------------------------------ |
| `IOException`            | Input/output operation fails   |
| `FileNotFoundException`  | File cannot be found/opened    |
| `SQLException`           | Database-related error         |
| `ClassNotFoundException` | Required class cannot be found |

//ERRORS
| Error                | Meaning                     |
| -------------------- | --------------------------- |
| `StackOverflowError` | Stack memory gets exhausted |
| `OutOfMemoryError`   | JVM runs out of memory      |
