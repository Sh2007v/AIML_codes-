/*
===========================================
            BINARY SEARCH NOTES
===========================================

Definition:
Binary Search is a searching algorithm used to find an element
in a SORTED array by repeatedly dividing the search space into
two halves.

Prerequisite:
✓ Array must be sorted (Ascending or Descending).

-------------------------------------------
Algorithm
-------------------------------------------
1. Initialize:
      low = 0
      high = n - 1

2. Repeat while (low <= high)

3. Find middle index:
      mid = low + (high - low) / 2

4. If arr[mid] == key
      Element Found

5. Else if key < arr[mid]
      Search Left Half
      high = mid - 1

6. Else
      Search Right Half
      low = mid + 1

7. If low > high
      Element Not Found

-------------------------------------------
Example
-------------------------------------------

Array:
Index : 0   1   2   3   4   5   6
Value :10  20  30  40  50  60  70

Search Key = 50

Step 1
low = 0
high = 6
mid = 3
arr[mid] = 40

50 > 40
Search Right Half

low = 4
high = 6

------------------------

Step 2

mid = 5
arr[mid] = 60

50 < 60
Search Left Half

low = 4
high = 4

------------------------

Step 3

mid = 4
arr[mid] = 50

Element Found

-------------------------------------------
Core Logic
-------------------------------------------

while(low <= high){

    int mid = low + (high - low) / 2;

    if(arr[mid] == key){
        return mid;
    }
    else if(key < arr[mid]){
        high = mid - 1;
    }
    else{
        low = mid + 1;
    }
}

-------------------------------------------
Time Complexity
-------------------------------------------

Best Case      : O(1)     (elem found at the middle)
Average Case   : O(log n) 
Worst Case     : O(log n)

-------------------------------------------
Space Complexity
-------------------------------------------

Iterative : O(1)

Recursive : O(log n)

-------------------------------------------
Advantages
-------------------------------------------

✓ Very fast for large sorted arrays.
✓ Reduces search space by half each iteration.
✓ More efficient than Linear Search.

-------------------------------------------
Disadvantages
-------------------------------------------

✗ Works only on sorted arrays.
✗ Sorting may take extra time if the array is unsorted.

-------------------------------------------
Linear Search vs Binary Search
-------------------------------------------

Linear Search
-------------
Array Need Not Be Sorted
Time Complexity : O(n)

Binary Search
-------------
Array Must Be Sorted
Time Complexity : O(log n)

--------------

Two important binary search patterns
1. Exact Search
   arr[mid] == target

2. Boundary / Property Search
   arr[mid] < arr[mid + 1]
