Sliding Windows
    : specialization of two pointers
    : used to solve problems having subarrays or substrings
    : to examine a continuous range of elements

    Types:
        Fixed-size windows : 
            window size remains constatnt
            Example:
            Find the maximum sum of any subarray of size k.
            [1, 3, 2, 6, -1, 4]
             └─────┘
               k=3
            Typical complexity:
                O(n) instead of O(n × k).

        Variable-size Windows :
            window size may change



FIXED - SLIDING WINDOWS
    maintain a constant subarray and slide it by one position
    don't recalculate what you have already calculated

    newSum = oldSum - outgoingElement + incomingElement

    Each element enters and leaves the window essentially once:

    Time: O(n)

    Space: O(1)

    Basic Java Template

    int windowSum = 0;

    // First window
    for(int i = 0; i < k; i++){
        windowSum += nums[i];
    }

    int maxSum = windowSum;

    // Slide the window
    for(int i = k; i < nums.length; i++){

        windowSum += nums[i];       // add new element
        windowSum -= nums[i - k];   // remove old element

        maxSum = Math.max(maxSum, windowSum);
    }

Basic Patterns
1.Longest Valid window
    General idea : Expand → Check → Shrink if invalid → Update maximum
    
    Basic Template

    int left = 0;
    int maxLength = 0;

    for(int right = 0; right < nums.length; right++){

        // Add nums[right]

        while(condition is invalid){
            // Remove nums[left]
            left++;
        }

        maxLength = Math.max(maxLength, right - left + 1);
    }

2. Shortest Valid Window
    Expand → Check → If valid, shrink → Update minimum

    Basic Template
    int left = 0;
    int minLength = Integer.MAX_VALUE;

    for(int right = 0; right < nums.length; right++){

        // Add nums[right]

        while(condition is valid){

            minLength = Math.min(minLength, right - left + 1);

            // Remove nums[left]
            left++;
        }
    }

3. Condition Based Window
    int left = 0;

    for(int right = 0; right < nums.length; right++){

        // Add nums[right]

        while(condition is violated){

            // Remove nums[left]
            left++;
        }

        // Process current valid window
    }
