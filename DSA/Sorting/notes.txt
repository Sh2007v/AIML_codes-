//SELECTION SORT

    comparison based sorting algorithm

    Algorithm:
        For every position i:
            Assume arr[i] is the minimum.
            Search the remaining array for a smaller element.
            If found, remember its index.
            Swap it with arr[i].
    
    Time Complexity:

        | Case    | Time      |
        | ------- | --------- |
        | Best    | **O(n²)** |
        | Average | **O(n²)** |
        | Worst   | **O(n²)** |

    it always scans the remaining array even if the array is sorted

    Core Logic (Pseudo Code)
        for i = 0 to n-2
            minIndex = i

        for j = i+1 to n-1
            if arr[j] < arr[minIndex]
                minIndex = j

        swap(arr[i], arr[minIndex])
    
// INSERTION SORT
idea : Take one element and insert it into its correct position among the elements to its left.
Implementation:

import java.util.Scanner;

public class InsertionSort {

    // Function to perform Insertion Sort
    public static void insertionSort(int[] arr) {
        int n = arr.length;

        for (int i = 1; i < n; i++) {
            int key = arr[i];
            int j = i - 1;

            // Shift elements of arr[0..i-1] that are greater than key
            // to one position ahead of their current position
            while (j >= 0 && arr[j] > key) {
                arr[j + 1] = arr[j];
                j--;
            }
            
            // Place key at its correct position
            arr[j + 1] = key;
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // Take array size input
        System.out.print("Enter number of elements: ");
        int n = sc.nextInt();

        int[] arr = new int[n];

        // Take array elements input
        System.out.println("Enter " + n + " elements:");
        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }

        // Sort the array
        insertionSort(arr);

        // Print sorted array
        System.out.println("Sorted Array:");
        for (int i = 0; i < n; i++) {
            System.out.print(arr[i] + " ");
        }

        sc.close();
    }
}

Insertion Sort works similarly to sorting playing cards in your hands. The array is virtually split into a sorted and an unsorted part. Values from the unsorted part are picked one by one and inserted into their correct position in the sorted part.

### How Insertion Sort Works

1. Assume the first element is already sorted.
2. Pick the next element and compare it with elements in the sorted part (moving right to left).
3. Shift all elements larger than the key one position to the right.
4. Insert the key into its correct position.
5. Repeat for all elements.

import java.util.Scanner;

public class InsertionSort {

    // Function to perform Insertion Sort
    public static void insertionSort(int[] arr) {
        int n = arr.length;

        for (int i = 1; i < n; i++) {
            int key = arr[i];
            int j = i - 1;

            // Shift elements of arr[0..i-1] that are greater than key
            // to one position ahead of their current position
            while (j >= 0 && arr[j] > key) {
                //comparison happened here
                arr[j + 1] = arr[j];
                //shift happened here
                j--;
            }

            arr[i] = sc.nextInt();
        }

        insertionSort(arr);

        sc.close();
    }
}
### Key Properties

* **Time Complexity**:
* **Best Case**: $O(n)$ *(when the array is already sorted)*
* **Average / Worst Case**: $O(n^2)$


* **Space Complexity**: $O(1)$ auxiliary space (in-place sorting).
* **Stability**: **Stable** (preserves the relative order of duplicate elements).
* **Key Advantage**: Highly efficient for small datasets or arrays that are already nearly sorted.
