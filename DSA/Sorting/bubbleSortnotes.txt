Bubble Sort
    
    repeatedly compares the two adjacent elements
    swap them if they are in wrong order
    largest unsorted element bubbles up

    Core logic:
//         for (int i = 0; i < n - 1; i++) {
//              for (int j = 0; j < n - i - 1; j++) {
//                     if (arr[j] > arr[j + 1]) {
//                              int temp = arr[j];
//                              arr[j] = arr[j + 1];
//                              arr[j + 1] = temp;
//                      }
//              }        
//          }

Time Complexity:

Best Case: O(n)
Worst Case: O(n^2)
Average Case: O(n^2)

Space Complexity:

    Key Formulas:
        No of passes: n-1
        Max Comparisons: n(n-1)/2
            For n = 5: 10 comparisons
