Creation

length() : tells you the number of the characters in a string
charAt() : gives you a particular character
s.charAt(s.length() - 1) = last character

ASCII values : 
'A' → 65
'B' → 66
'C' → 67

'a' → 97
'b' → 98
'c' → 99

'0' → 48
'1' → 49
